Hello!
This is my small complex matrix calculator which done for Java practice work.
Features:
1. "Create" matrices and store/extract them with save and load functions.
2. Can process some arithmetic operations with matrices.
3. Find determinants and inversed matrices, transpose.
4. Have a basic CLI.

You can have a more detailed view on the functional by using a "help" command while using the programm.
However, there is a fast introduction to all possible commands:
Full list:
  "help - get list of commands and Show_determinant status.", 
  "stop - stop.", 
  "mkm - Make Matrix.", 
  "mls - Listing.", 
  "sum - Summarise matrices.",
  "pd - Product of two matrices.", 
  "dif - Difference.", 
  "t - Transpose.", 
  "det - Find determinant.",
  "sd - Change Show_determinant option: Show determinant in listing or not.", 
  "div - Divide matrix. Equals to A * A^-1.",
  "inv - Find inversed matrix."
